# ForjaIA · materiales

- `encargo_en_una_frase.txt`: idea de la app y crédito de la idea original, listos para pegar.
- `cuaderno_pruebas_diagnosticas.ipynb`: cuaderno ejecutado que sirve de idea original; súbelo en «Ficheros».
- Prueba primero con «IA simulada (no gasta)» y después con tu clave.
- Flujo: Material («Entender el material») → Preguntas («Proponer las preguntas») → Autoría (nombre, afiliación y ORCID; aquí va también «Quién aportó la idea») → Construcción → Prueba → Publicación.
- Para publicar: repositorio en GitHub → GitHub Pages → Zenodo (versión 1.0.0, DOI y CITATION.cff). Encargos alternativos en «Veinte encargos para ForjaIA» (enlace en el portal).
